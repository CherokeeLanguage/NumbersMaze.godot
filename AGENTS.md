# AGENTS.md — NumbersMaze.godot

Agent notes for the Cherokee Numbers Maze game. Only repo-specific facts —
nothing here is guessable from filenames.

## Engine

- Godot **3.x** project: `project.godot` is `config_version=4`; GDScript 1.x
  syntax throughout (`File.new()`, `yield()`, `onready var`, `setget`,
  `parse_json`). Never open or import with a Godot 4.x editor.
- No `godot` binary is on PATH in this environment. Extracted 3.x editor builds
  live under `~/godot/previous/` (3.2.4 exists only as zips). Smoke-check a
  change with: `<godot3-binary> -e --path . --quit` (editor mode — imports
  assets, surfaces script errors; plain game-mode `--path .` runs **without**
  importing).
- Android export templates were built from 3.2.4-rc3 (`android/.build_version`);
  engine source rebuilds via `~/godot/rebuild-android.sh` (scons, all archs).
- No CI, no test framework, no lint config. GDScript warnings for unsafe
  property/method access and casts are enabled in `project.godot` `[debug]` —
  keep new code warning-clean.
- `misc/TestScene.tscn` is a scratch harness (runs level 16 with dice, quits on
  `btn_select`): `<godot3-binary> --path . res://misc/TestScene.tscn`

## Architecture

- Flow: `main/Main.tscn` → `main/Main.gd` (menus via `ui/menus/BaseMenu.gd`
  subclasses, swapped through `FadeOutIn` transitions) → `main/World.gd` →
  `levels/LevelMap.gd`.
- Mazes are **procedurally generated** per level number (`scripts/maze/MazeGenerator.gd`,
  seeded from the level) — there are no level data files. Challenges are computed
  in `scripts/dice/Challenges.gd`; dice faces are 1–6, 20, 80, 300.
- Autoloads are referenced by their autoload names, never class names:
  `consts` (sound-effect registry), `dieTracker`, `numberAudio` (Cherokee
  number audio), `PackedScenes`.
- `nodes/PackedScenes.gd` is the central scene registry — every instanced
  scene must be preloaded there (workaround for Godot 3 "already loaded"
  packed-scene errors). Add new scenes here, don't `preload()` them ad hoc.
- Global script classes are registered in `project.godot`
  `_global_script_classes`; a new `class_name` script takes an editor pass to
  register.
- Saves are `user://<slot>.json`, written by `scripts/classes/GameSlot.gd`.
- Gamepad: SDL mappings from `gamepad/controllerdb.txt` are loaded at runtime
  by `main/Main.gd`. TV builds are selected at runtime by `--tv=true` (see
  `Main.gd`); `export_presets-tv.cfg` is the tracked Android TV preset.

## Gotchas

- New sound effect = drop the `.ogg` into `audio/effects/` **and** add its
  filename to `audio/effects/plist.txt` — the `consts` autoload reads that
  list at init.
- Export include filters: main presets (`export_presets.cfg`) ship
  `*.txt, *.json, *.bbcode`; the TV preset file ships `*.txt, *.json` only —
  `.bbcode` game text does not ship in TV exports. `assets/*` is **excluded**
  from all exports — it is source material (artwork, adb scripts), not
  runtime content.
- `text/changelog.txt` is generated by `./update-changelog.sh` (git log +
  `text/changelog.prev*.txt`) and displayed in-game; don't hand-edit it.
- Editor caches `.import/` (Godot 3.x layout) and `.godot/` (4.x-era cache
  left by an accidental Godot 4 open) are both gitignored and regenerate
  freely; don't commit cache churn.
- `export_presets.cfg` is gitignored and holds machine-local signing config
  including keystore credentials — never print, copy, or commit its contents.
  Export output lands in gitignored `tmp/` and `html5/`.

## Deck
