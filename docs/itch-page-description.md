# itch.io page description — Cherokee Numbers Maze

<!-- the description body begins at the cut line -->

---

Learn the Cherokee numbers — ᏣᎳᎩ ᏗᏎᏍᏗ — by playing a maze game.

Cherokee Numbers Maze is a simple maze game that helps you learn the
Cherokee numbers. Wander around the maze and collect dice together that
match the challenge you were given — then explode them. Complete all of a
level's challenges and you move on to the next, larger level with more
numbers to learn.

**Gamepad:** left stick or D-pad to move · **[A]** fireball · **[X]** pick
up dice · **[Y]** drop dice

**Keyboard:** arrow keys to move · **[F]**, **[Space]**, or **[Enter]**
fireball · **[D]** pick up dice · **[S]** drop dice

**Platforms:** play it right here in your browser, or download builds for
Windows, macOS, Linux, and Android — every build is served by this itch
page.

Demo video: <https://www.youtube.com/watch?v=tj6c0UGRMF4>
